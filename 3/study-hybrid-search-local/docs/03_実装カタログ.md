## 2. PostgreSQL テーブル

| テーブル | 役割 |
|---|---|
| `properties` | 不動産マスタ (Meilisearch / pgvector の正本) |
| `embeddings` | ME5 embedding (`vector(384)`、cosine distance ANN) |
| `feature_mart_property_features_daily` | rerank 用 dynamic feature (ctr / fav_rate / inquiry_rate) |
| `ranking_log` | /search の実行ログ。LightGBM 再学習データソース |
| `feedback_events` | /feedback で受け取る行動ログ |

DDL は [`../definitions/postgres/migrations/0001_init.sql`](../definitions/postgres/migrations/0001_init.sql)。

## 3. Port × Adapter 対応表

| Port | Adapter | データソース |
|---|---|---|
| `LexicalSearchPort` | `MeilisearchLexicalSearch` | Meilisearch (Docker) |
| `SemanticSearchPort` | `PgVectorSemanticSearch` | PostgreSQL `embeddings` + pgvector `<=>` |
| `EncoderClient` | `LocalE5Encoder` | sentence-transformers in-process |
| `RerankerClient` | `LocalLightGBMReranker` | LightGBM Booster in-process |
| `FeatureFetcher` | `PostgresFeatureFetcher` | PostgreSQL `feature_mart_property_features_daily` |
| `RankingLogPublisher` | `PostgresRankingLogPublisher` | PostgreSQL `ranking_log` INSERT |
| `FeedbackRecorder` | `PostgresFeedbackRecorder` | PostgreSQL `feedback_events` INSERT |
| `CandidateRetriever` | `LocalCandidateRetriever` | lexical + semantic + RRF + Postgres `properties` enrichment |

## 4. API エンドポイント

| メソッド + Path | 役割 |
|---|---|
| GET `/health` | liveness |
| POST `/search` | 自由文クエリ + フィルタ → 物件ランキング上位 N 件 (3 段検索) |
| POST `/feedback` | 行動ログ受付 (click / favorite / inquiry) |

入出力スキーマは [`../app/schemas/search.py`](../app/schemas/search.py)。

## 5. Make ターゲット

| Target | 動作 |
|---|---|
| `make build` | Docker image build (api / seed / trainer / evaluator) |
| `make up` | postgres + meilisearch + redis up + healthcheck wait |
| `make seed` | `pipeline.data_job.main` (合成 1000 件投入) |
| `make train` | `pipeline.training_job.main` (LambdaRank → `model.lgb`) |
| `make evaluate` | `pipeline.evaluation_job.main` (NDCG@10 評価) |
| `make serve` | search-api を :8000 で foreground 起動 |
| `make api-dev` | uv run uvicorn (host 側、Docker なし) |
| `make test` / `make check` / `make check-layers` / `make verify-pipeline` | テスト / CI 同等 / 境界検査 / E2E |
| `make run-all-core` | build → up → seed → train → test |
| `make down` / `make clean` | 停止 / 全削除 |
