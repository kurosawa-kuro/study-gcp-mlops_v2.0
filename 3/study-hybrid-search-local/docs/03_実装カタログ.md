## 2. PostgreSQL テーブル

| テーブル | 役割 |
|---|---|
| `properties` | 不動産マスタ (Meilisearch / pgvector の正本) |
| `embeddings` | ME5 embedding (`vector(384)`、cosine distance ANN) |
| `feature_mart_property_features_daily` | rerank 用 dynamic feature (ctr / fav_rate / inquiry_rate) |
| `ranking_log` | /search の実行ログ。LightGBM 再学習データソース |
| `feedback_events` | /feedback で受け取る行動ログ |

DDL は [`../definitions/postgres/migrations/0001_init.sql`](../definitions/postgres/migrations/0001_init.sql)。

host port: postgres は **5433** に bind (5432 を使う他プロジェクトとの衝突回避)。container 間通信は `postgres:5432` (内部) のままなので影響なし。

## 3. Port × Adapter 対応表

| Port | Adapter (実体) | データソース | 出自 |
|---|---|---|---|
| `LexicalSearchPort` | `MeilisearchLexicalSearch` | Meilisearch (Docker) BM25 + filter | Phase 7 流用 + 認証簡素化 (master key + Docker hostname、Identity Token / impersonation 撤去) |
| `SemanticSearchPort` | `PgVectorSemanticSearch` | PostgreSQL `embeddings` + pgvector `<=>` (cosine distance) | Phase 3 新規 |
| `EncoderClient` | `LocalE5Encoder` | sentence-transformers `intfloat/multilingual-e5-small` (in-process) | Phase 3 新規 |
| `RerankerClient` | `LocalLightGBMReranker` | LightGBM Booster (in-process、`model.lgb` 直読み) | Phase 3 新規 |
| `FeatureFetcher` | `PostgresFeatureFetcher` | PostgreSQL `feature_mart_property_features_daily` | Phase 3 新規 |
| `RankingLogPublisher` | `PostgresRankingLogPublisher` | PostgreSQL `ranking_log` INSERT (Pub/Sub の代替) | Phase 3 新規 |
| `FeedbackRecorder` | `PostgresFeedbackRecorder` | PostgreSQL `feedback_events` INSERT | Phase 3 新規 |
| `CandidateRetriever` | `LocalCandidateRetriever` | lexical + semantic + RRF + Postgres `properties` enrichment を統合 | Phase 3 新規 (Phase 7 `BigQueryCandidateRetriever` 相当) |
| `SynonymExpanderPort` | `RedisSynonymExpander` | Redis (Docker) `syn:<token>` SET を SMEMBERS して query expansion (例: `マンション` → `マンション アパート 共同住宅`) | Phase 3 SYN-1 (Phase 7 SYN-1 と同型 Port、Phase 7 では Cloud Memorystore に置換) |
| `SearchCachePort` | `RedisSearchCache` | Redis (Docker) `search:v1:<sha256>` STRING に `/search` レスポンスを SETEX (TTL=60s)。HIT で encoder/retriever/reranker/publisher を全 skip。`request_id` はキャッシュに含めず、HIT 時は live request_id をスタンプ | Phase 3 SYN-2 (Phase 4+ で Cloud Memorystore に差し替え可) |

中核 RRF (`app/services/ranking.py::rrf_fuse`) と SearchService / FeedbackService / Domain / Schema / Port 定義 / 5 noop_adapters / Router / mapper / middleware / `tests/_fakes/` は Phase 7 から流用 (改修ゼロまたは popularity_scorer 系の削除のみ)。SYN-1 で `SynonymExpanderPort` + adapter を Phase 7 から並行追加。SYN-2 (`SearchCachePort` + `RedisSearchCache`) は Phase 3 で先行実装。Redis instance は両 SYN で共有 (key prefix `syn:` / `search:` で分離)。

## 4. API エンドポイント

| メソッド + Path | 役割 | 実装 |
|---|---|---|
| `GET /health` | liveness | `app/api/routers/health_router.py` |
| `GET /readyz` | readiness (`rerank_enabled` / `model_path` 表示) | 同上 |
| `POST /search` | 自由文クエリ + フィルタ → 物件ランキング上位 N 件 (3 段検索) | `app/api/routers/search_router.py` |
| `POST /feedback` | 行動ログ受付 (click / favorite / inquiry) | `app/api/routers/feedback_router.py` |
| `GET /` | `/ui/` へ 308 redirect | `app/api/routers/ui_router.py` |
| `GET /ui/` | Browser UI (Pico-admin dark theme HTML) | 同上 |
| `GET /static/css/*` | Pico-admin CSS 5 ファイル | `app.mount("/static", StaticFiles)` |
| `GET /static/js/search_ui.js` | UI ロジック JS (`HybridSearchUI.init`) | 同上 |
| `GET /docs` | Swagger UI (FastAPI 自動) | FastAPI default |

入出力スキーマは [`../app/schemas/search.py`](../app/schemas/search.py)。

## 5. Make ターゲット

| Target | 動作 |
|---|---|
| `make build` | Docker image build (search-api / seed / trainer / evaluator / seed-synonyms) |
| `make up` | postgres + meilisearch + redis up + healthcheck wait (host port 5433)。Redis は SYN-1 同義語辞書 + SYN-2 `/search` キャッシュの両方の backend |
| `make seed` | `pipeline.data_job.main` (合成 1000 件投入) → 続けて `make seed-synonyms` |
| `make seed-synonyms` | `pipeline.data_job.components.sync_synonyms` で `definitions/synonyms/real_estate_ja.yaml` を Redis `syn:<token>` SET に流し込む。Redis volume を持たないので container 再起動毎に再投入が必要 |
| `make train` | `pipeline.training_job.main` (LambdaRank → `model.lgb`) |
| `make evaluate` | `pipeline.evaluation_job.main` (NDCG@10 評価) |
| `make serve` | search-api を :8000 で foreground 起動 |
| `make api-dev` | uv run uvicorn (host 側、Docker なし、postgres は localhost:5433) |
| `make test` / `make check` / `make check-layers` / `make verify-pipeline` | テスト / CI 同等 / 境界検査 / integration E2E |
| `make run-all-core` | build → up → seed → train → test |
| `make down` / `make clean` | 停止 / 全削除 |
